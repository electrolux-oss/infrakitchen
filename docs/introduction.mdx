**InfraKitchen** is a self-service infrastructure provisioning platform. Platform engineers define reusable, standardized infrastructure as code; developers provision it through a guided interface — without needing deep knowledge of cloud platforms or IaC tools.

Under the hood, InfraKitchen generates Terraform/OpenTofu code for every Resource, and can publish it to your Git repositories as pull requests for review. Every change is audit-logged.

## How InfraKitchen Helps

### For Platform Teams

- **Define infrastructure once** and reuse it across environments and accounts through a template hierarchy.
- **Enforce standards** with versioned templates and variable validation rules.
- **Audit every change** for compliance, visibility, and traceability.

### For Developers

- **Provision approved infrastructure** by selecting a template and filling out a form.
- **Work independently** — governance stays with the platform team.
- **Stay informed** — every change is version-controlled and auditable.

## Getting Started

**Platform engineers** set up the foundation once:

1. Set up [Integrations](concepts/overview) (e.g., AWS, GitHub).
2. Register Code Repositories and define Templates in a parent/child hierarchy.
3. Add Template Versions and configure variable validation rules.

**Developers** then provision self-service, with no setup of their own:

1. Select a [Template](concepts/template) and Template Version.
2. Fill out the form generated from the template's variables.
3. Provision — InfraKitchen runs the plan and apply, and reports progress.

To see it in practice, continue to the [Quick Start](quick-start).
